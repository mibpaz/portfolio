# Ashl's Portfolio

This is my portfolio. It should have a whimsy, nerdy theater kid vibe while showcasing my abilities like an RPG.

## Tech Stack

- Next.js
- TailwindCSS
- HeroUI

Use `bun` instead of `npm`.

## Project structure (semantic description)

The app has a single page (`app/page`) composed of the following sections (`components/sections`):

- hero.tsx: Flashy hero to gauge attention
- skills.tsx: Inventory-style skillset display
- projects.tsx: A list of some projects.
- about.tsx: Some text about me and my career
- social.tsx: Links to my social media

The app has a simple navbar with anchor links.
Additionally, a share section with some jokes to really emanate the funny vibe.
